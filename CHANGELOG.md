# Changelog

## 0.1.0 - 2026-10-12

First versioned release: practical, scoped engineering workflows.

### Changed
- Reworked all 32 skills with focused triggers, concrete examples, stop conditions, and observable evidence.
- Removed repeated routine approval demands and numeric confidence theater; preserve existing authorization and explicit delegation.
- Unified testing and vertical slices around failing check -> implementation -> regression verification -> refactor.
- Added specific security, accessibility, migration, retries, rollout, and observability guidance.
- Scoped load testing, documentation, planning, and release checks to the actual task risk.
- Replaced unsupported comparative superiority and runtime-enforcement claims with explicit limits.
- Standardized portable frontmatter on name and description.

### Added
- Dependency-free Python installer with dry run, selection, project/user paths, collision refusal, and identical-install skipping.
- Repository metadata, catalog/count, and local Markdown link/anchor validation.
- Regression tests and GitHub Actions for Ubuntu/Windows on Python 3.10/3.13.
- Behavioral evaluation prompts, scoring protocol, and an executable isolated fixture.
- Exact Claude Code/Codex installation instructions and contribution guidance.

### Validation limits
Structural checks and helper tests do not prove agent compliance, product correctness, or superiority over another collection. Live comparative agent evaluations and native agent discovery tests are not yet published.
