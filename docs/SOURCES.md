## Editorial choices

Each addition narrows the trigger, uses the existing project tools, defines failure/recovery behavior, and separates observed verification from claims. Examples and prose were newly authored. Version-specific commands and arbitrary universal defaults were avoided; workflows direct agents to verify installed versions and official documentation when implementation depends on them.
