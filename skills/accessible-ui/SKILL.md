# UI Engineering — Clear, Accessible, Fast

Prefer simple, accessible components over clever ones.

## Process
1. Define the component's single responsibility and props.
2. Ensure keyboard and screen-reader access.
3. Avoid unnecessary re-renders and heavy client work.
4. Use semantic HTML.
5. Verify with real interaction, not just visual check.

## Verification
- [ ] Keyboard navigable
- [ ] Semantic markup used
- [ ] No obvious performance regressions
- [ ] Props and behavior documented
