# Idea Refinement — From Fuzzy to Concrete

Do not jump to a single solution. Generate options, then converge.

## Process
1. Capture the raw idea and known constraints in one paragraph.
2. Generate 3 divergent options (different approaches, not variations of one).
3. List trade-offs for each (speed, complexity, risk, fit).
4. Recommend one and state why.
5. Confirm with user before writing any spec.

## Verification
- [ ] At least 3 options generated
- [ ] Trade-offs explicit
- [ ] Single recommendation with rationale
- [ ] User confirmed before proceeding
